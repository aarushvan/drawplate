Shared local runtime architecture

All five packages share isomorphic ESM cores that run identically in Node.js 26 and the browser, paired with a native C++20 DSP binary.

  • Zero runtime npm dependencies, using built-in node:sqlite, node:http, and node:test.
  • Browser-native WebGL2 FBO rendering and lock-free 48 kHz Web AudioWorklet DSP.
  • Plain JSON cassettes, SQLite snapshots, and 16-bit PCM WAV files stored on disk.

What license covers Drawplate tools?

All Drawplate packages, the CLI, and the C++20 renderer ship under the MIT license.

Which runtimes are supported?

The workbench runs in browsers with WebGL2 and Web Audio. The CLI runs on Node.js 22.13 or newer.

Do these tools run offline?

Every tool runs strictly offline on localhost with all state kept on local disk.

How do I build local Drawplate tools?

There are no npm packages to install. Run npm run build:native before npm test and npm run bench.
